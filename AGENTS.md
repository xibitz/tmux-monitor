# Instruksi untuk agent di repositori ini

1. Baca [MEMORY.md](MEMORY.md) sebelum melanjutkan pekerjaan. File tersebut berisi
   keadaan terkini, langkah implementasi, aturan, pengujian dan titik lanjut.
2. Gunakan tabel status di [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) sebagai
   tasklist. Baca [PRD.md](PRD.md) dan kontrak API untuk task yang sedang dikerjakan.
3. Perbarui MEMORY.md dan status task setelah checkpoint dan sebelum berhenti,
   termasuk jika token/context hampir habis. Jangan tandai selesai tanpa bukti.
4. Jangan commit `.env`, `.data`, key, token, data terminal, atau alamat tailnet
   pribadi dari konfigurasi pengguna. Jangan menimpa perubahan pengguna.
