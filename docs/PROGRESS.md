# Progres implementasi

Dokumen status utama dipusatkan agar tidak berbeda antar-file:

- [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md): status setiap task, checklist, dependensi dan acceptance gate.
- [MEMORY.md](../MEMORY.md): pekerjaan aktual, langkah implementasi, aturan, bukti pengujian dan titik lanjut agent.
- [docs/api-v1.md](api-v1.md): kontrak yang benar-benar sudah diimplementasikan.

Baca MEMORY.md terlebih dahulu saat melanjutkan chat/agent baru. Jangan menganggap deskripsi kriteria “Selesai” sebagai status task; lihat tabel pelacakan aktual.
